Practical 1 — Design and Implement Basics Embedded Circuits

Design and implement basics embedded circuits covering three sub-practicals: Automatic Alarm System, Timer Based Buzzer, and Sensor Based Counting Device. PROTEUS

Practical 1.1 — Automatic Alarm System

Alarm should get triggered by sensor.

Part 1: Writing C Program in Keil Software and creating Hex file

Step 1: Project → New Project → Search your Folder → Give name to project → Select Atmel → AT89C51 → Click Ok.
Step 2: File → New file → Text Window is open → Type program → Save file by .c extension
Code:
#include<reg51.h>
sbit sensor=P1^0;
sbit rs=P1^1;
sbit rw=P1^2;
sbit en=P1^3;
sbit buzzer=P3^0;

void lcdinit();
void lcddat(unsigned char);
void lcdcmd(unsigned char);
void lcddis(unsigned char *);
void delay();

void main()
{
    buzzer=0; sensor=0;
    back: lcdinit();
    lcddis("FIRE ALERT");
    lcdcmd(0xc0);
    lcddis("SYSTEM");
    delay();
    while(1)
    {
        if(sensor==1)
        {
            lcdcmd(0x01);
            lcddis("FIRE OCCURED");
            buzzer=1;
        }
        goto back;
    }
}

void lcdinit()
{
    lcdcmd(0x38); lcdcmd(0x01); lcdcmd(0x10); lcdcmd(0x0c); lcdcmd(0x80);
}

void lcdcmd(unsigned char val)
{
    P2=val; rs=0; rw=0; en=1; delay(); en=0;
}

void lcddat(unsigned char dat)
{
    P2=dat; rs=1; rw=0; en=1; delay(); en=0;
}

void lcddis(unsigned char *s)
{
    unsigned char w;
    for(w=0;s[w]!='\0';w++)
    {
        lcddat(s[w]);
    }
}

void delay()
{
    unsigned int v1;
    for(v1=0;v1<10000;v1++);
}
Step 3: Click on target → Source group → right click → Add existing file → select program file → Click on Add.
Step 4: Right click on target → Option for target → Change frequency to 11.0592 MHz → Click on use on-chip ROM → Go to output label → Click on Create Hex file → Ok.
Step 5: Project → Click on Build target.

Part 2: Designing circuit for Alarm system in Proteus

Step 1: Proteus 8 professional → New project → name for project → Finish.
Step 2: From P (Device selector) search and add the components:
  • AT89C51
  • Buzzer — active DC Operated Buzzer Output Via Sound Card
  • LCD: LM016L 16x2 Alphanumeric LCD
  • Button (SPST Push button)
Step 3: Design the Circuit → Connect ground and power from terminals.
Step 4: Double click on Micro controller → Select HEX file from program file → Change Clock frequency to 11.0592MHz → Click Ok.

Output

  • When Fire sensor is OFF (fire not detected) — LCD shows "FIRE ALERT SYSTEM".
  • When fire is detected (Fire sensor ON) — LCD shows "FIRE OCCURED" and buzzer is activated.

Practical 1.3 — Sensor Based Counting Device

Part 1: Writing C Program in Keil Software and creating Hex file

Step 1: Project → New Project → Search your Folder → Give name to project → Select Atmel → AT89C51 → Click Ok.
Step 2: File → New file → Text Window is open → Type program → Save file by .c extension
Code:
#include<reg51.h>

sbit sen1=P1^0; // entry
sbit sen2=P1^1; // exit
sbit rs=P1^2;
sbit rw=P1^3;
sbit en=P1^4;

void lcdcmd(unsigned char);
void lcddat(unsigned char);
void delay();
void lcddis(unsigned char *s, unsigned char r);
void lcdconv(unsigned char);

void main()
{
    unsigned char x,y;
    lcdcmd(0x38); delay();
    lcdcmd(0x01); delay();
    lcdcmd(0x10); delay();
    lcdcmd(0x0c); delay();
    lcddis("WELCOME",7);
    lcdcmd(0xc0);
    delay();
    lcddis("VISITOR COUNTER",15);
    delay();
    lcdcmd(0x01); delay();
    while(1)
    {
        if(sen1==0)
        {
            lcdcmd(0x80); delay();
            lcddis("ENTRY:",6);
            lcdcmd(0x87); delay();
            x=x+1;
            lcdconv(x); delay();
        }
        if(sen2==0)
        {
            lcdcmd(0xc0); delay();
            lcddis("EXIT:",5);
            lcdcmd(0xc6); delay();
            y=y+1;
            lcdconv(y); delay();
        }
    }
}

void lcdcmd(unsigned char val)
{
    P2=val; rs=0; rw=0; en=1; delay(); en=0;
}

void lcddat(unsigned char dat)
{
    P2=dat; rs=1; rw=0; en=1; delay(); en=0;
}

void lcddis(unsigned char *s, unsigned char r)
{
    unsigned char w;
    for(w=0;w<r;w++)
    {
        lcddat(s[w]); delay();
    }
}

void lcdconv(unsigned char num)
{
    unsigned char p,n;
    p=num/10; n=num%10;
    p=num+0x30; n=n+0x30;
    lcddat(p); lcddat(n);
}

void delay()
{
    unsigned int k,l;
    for(k=0;k<1000;k++);
    for(l=0;l<100;l++);
}

Practical 2 — UART Communication Between Two Embedded Devices

Demonstrate communication between two embedded devices using UART port. PROTEUS

Part 1: Writing C Program in Keil Software and creating Hex file

Step 1: Project → New Project → Search your Folder → Give name to project → Select Atmel → AT89C51 → Click Ok.
Step 2: File → New file → Text Window is open → Type program → Save file by .c extension

Code 1:

#include<reg51.h>

void main()
{
    /* Mode 1, reception enable */
    SCON=0X50;
    /* Timer 1, 8-bit auto reload mode */
    TMOD=0X20;
    TH1=-3;       /* Load value baud rate */
    TR1=1;        /* Start timer 1 */
    SBUF='I';     /* Load char in buffer */
    while(TI==0);
    TI=0;
}

Code 2:

#include <reg51.h>

void UART_Init()
{
    TMOD = 0x20;   /* Timer 1, 8-bit auto reload mode */
    TH1 = 0xFD;   /* Load value for 9600 baud rate */
    SCON = 0x50;  /* Mode 1, reception enable */
    TR1 = 1;      /* Start timer 1 */
}

void Transmit_data(char tx_data)
{
    SBUF = tx_data;    /* Load char in SBUF register */
    while (TI==0);     /* Wait until stop bit transmit */
    TI = 0;            /* Clear TI flag */
}

void String(char *str)
{
    int i;
    for(i=0; str[i]!=0; i++)   /* Send each char of string till NULL */
    {
        Transmit_data(str[i]);  /* Call transmit data function */
    }
}

void main()
{
    UART_Init();       /* UART initialize function */
    String("test");    /* Transmit 'test' */
    while(1);
}

Practical 3 — IoT Bus Ticketing System

Build an IoT system to send ticket before entering the bus. PROTEUS Arduino IDE

Part 1: Writing C Program in Arduino IDE and creating Hex file

Step 1: Open Arduino → New file → Write program → Save file.

Code:

#include <Servo.h>

int count = 0;
char c;
String id;
Servo myservo;

void setup()
{
    Serial.begin(9600);
    myservo.attach(9);
    myservo.write(0);
    pinMode(13, OUTPUT);
    Serial.println("Please scan your RFID TAG");
}

void loop()
{
    while(Serial.available() > 0)
    {
        c = Serial.read();
        count++;
        id += c;
        if(count == 12)
        {
            Serial.print(id);
            if(id == "AB123456789A")  // Define valid tag id here
            {
                Serial.println("Valid TAG");
                digitalWrite(13, HIGH);
                myservo.write(180);
                delay(4000);
                myservo.write(0);
            }
            else
            {
                digitalWrite(13, LOW);
                Serial.println("Invalid TAG");
                myservo.write(0);
            }
        }
    }
    count = 0;
    id = "";
    delay(500);
}
Step 2: Click on Verify option and verify/compile the code.
Step 3: After verifying the program, select path of the hex file, copy that path and paste it in the Proteus file.

Part 2: Designing circuit in Proteus

Note: If Arduino is not added in Proteus, download Arduino library. Right click C drive and choose show hidden folder. Open Program Data and copy the .lib files in the library folder.

Valid tag ID: AB123456789A | Test tag: 1234567

Step 1: Proteus 8 professional → New project → name for project → Finish.
Step 2: From P (Device selector) search and add the components:
  • SIMULINO UNO controller
  • MOTOR-PWMSERVO — Animated PWM Controlled Servo motor
  • Virtual Terminal from instruments
Step 3: Design the Circuit.
Step 4: Double click on controller → Select HEX file from program file → Click Ok.

Output

  • When simulation starts, the servo motor is at -90 degrees (door closed).
  • When a valid ticket code is entered in the Virtual Terminal, the door opens (servo motor angle changes to +90 degrees) and returns to initial position after a delay.
  • Invalid codes show "Invalid TAG" and the door stays closed.

Practical 5 — Rain Alarm IoT Application

Develop an IoT application that will raise an alarm whenever it is going to rain outside based on weather prediction data. CISCO Packet Tracer

Step 1: Open Cisco Packet Tracer.
Step 2: Design the circuit.
Step 3: Search and take components: Humidity sensor, MCU-PT, and Alarm. Connect A0 pin of MCU with A0 pin of Humidity sensor and D1 pin of MCU with D0 pin of Alarm using IoT custom cable.
Step 4: Select MCU-PT → right click on it → Programming → New button → Create a new file (motion detection.js) → Write the motion detection program.

Code (motion detection.js):

function setup()
{
    pinMode(0, INPUT);
    pinMode(1, OUTPUT);
}

function loop()
{
    var humid = analogRead(0);
    Serial.println(humid);

    if(humid >= 500)
    {
        digitalWrite(1, HIGH);
    }
    else
    {
        digitalWrite(1, LOW);
    }
}
Step 5: Click on run button and run the program.

Output

  • When humidity level is greater than 500 (i.e., when it is raining outside), the Alarm is turned ON.
